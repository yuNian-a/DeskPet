# 成步堂龙一状态显示器素材

## 状态映射表

| 状态码 | 状态名 | 成步堂表情 | 文件名 |
|--------|--------|------------|--------|
| 0 | BOOT (启动) | 通常 | cbt1-通常 |
| 1 | ANALYZING (分析中) | 思考 | cbt1-思考 |
| 2 | PROCESSING (处理中) | 集中 | cbt1-集中 |
| 3 | EXECUTING (执行中) | 异议！| cbt1-异议 |
| 4 | SUCCESS (成功) | 得意 | cbt1-得意 |
| 5 | FAILURE (失败) | 尴尬 | cbt1-尴尬 |
| 6 | CRITICAL (严重错误) | 绝望 | cbt1-绝望 |
| 7 | DISPLAY (等待中) | 看纸 | cbt1-看纸 |
| 8 | IDLE (空闲) | 通常(眨眼) | cbt1-通常 |

## 文件清单

共 42 个文件：
- 14 套表情 × (PNG原画 + GIF动画)
- 特殊动画：被扔咖啡、被扔头发、震惊

## 使用方法

1. 启动显示器：`launch_display.vbs`
2. TCP 发送状态到 127.0.0.1:19876
3. 或使用 Hook 自动触发
